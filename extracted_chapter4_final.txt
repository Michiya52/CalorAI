 
                Chapter 5: Result and Discussion           5.1 Testing and Discussion           5.1.1 Unit Testing             Unit testing was conducted across fifteen modules in total: the eight originally planned device-testable modules, six additional modules identified during code verification as having no prior test coverage (Dashboard, Manual Search, Suggestion Cards, Meal History, Meal Detail, and Profile), and one module verified by direct code tracing rather than on-device testing. Each device-tested module was executed on the CalorAI prototype running on a physical Android device (minimum SDK 26). The Calorie Calculator module is not exposed through any user interface and cannot be black-box tested on-device; its results were instead verified by tracing the real calculateBMR() and calculateTarget() implementation directly against the documented Mifflin-St Jeor formula, which is a legitimate verification method for a pure, deterministic function. The Portion Scaler module described in the original test plan did not correspond to how portion selection actually works in the app and has been removed from this chapter; portion adjustment is already covered under the Portion Selection Screen tests in Section 5.1.1.6. The six newly identified modules have not yet been executed and are recorded as Pending below, with their test cases already added to Chapter 4 Section 4.7.1.10 onward.         5.1.1.1 Login Screen
